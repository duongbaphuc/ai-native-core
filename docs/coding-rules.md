# Coding Rules & Engineering Standards

## 1. Code Style & Conventions
- Maintain clean, self-documenting code with clear variable and function naming.
- Follow PEP 8 (Python) or ESLint/Prettier (Node.js/TypeScript) standards.

## 2. Testing Standards
- Aim for >= 80% test coverage on critical business logic.
- Place unit tests in `/tests/unit` and integration tests in `/tests/integration`.

## 3. AI Code Assistant Rules
- Always review AI-generated code against this document and `CONTRIBUTING.md`.
- No sensitive data or hardcoded credentials in code or prompts.
